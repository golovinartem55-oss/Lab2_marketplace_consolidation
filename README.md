## Цель работы
Освоить полный цикл консолидации данных из нескольких источников: загрузку, проверку качества, очистку, построение реляционной модели, расчёт выручки и формирование обоснованных управленческих решений.

## Постановка задачи (Вариант 10)
Необходимо объединить справочник субъектов (CSV), события с объёмом (Excel) и цены, заданные для событий (JSON).
* **Предметная область:** Маркетплейс
* **CSV:** Продавцы (справочник субъектов)
* **XLSX:** Заказы (события, объём в единицах: единиц)
* **JSON:** Цены товаров (цены, разрез: категория товара)
* **Аналитическая задача:** Топ продавцов и доля категорий в обороте.

## Ключевые результаты и проверки
* **Аудит качества:** найдены дефекты по 5 измерениям (пропуски, дубликаты справочника, битые внешние ключи `E999`, отрицательные цены, два формата даты, числа с валютой).
* **Очистка:** ведется журнал изменений. Пропуски не заменены нулями. Ошибочные строки (69 шт.) отправлены в карантин, а не удалены молча.

* **Самопроверка:** ноутбук успешно проходит встроенный тест **11 из 11**.
